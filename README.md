# CAMING-WITH-FRIENDS
A cozy, free-to-play 3D browser multiplayer camping game for up to 5 friends—featuring voice chat, mountain trekking, fishing, firewood chopping, a day/night cycle, and campfire party games on PC &amp; mobile.

# 🏕️ Cozy Campfire — 3D Multiplayer Browser Hangout

A free, browser-based 3D multiplayer camping game built for friends to hang out, explore nature, and play social party games together on **PC and mobile**—no downloads or paid servers required.

## ✨ Features

* **Private 5-Player Lobbies:** Create or join a private campsite using a custom **Room Name** and **Password**.
* **Built-in Voice Chat (Mic):** Talk live with friends around the campsite using peer-to-peer WebRTC audio with a quick mute/unmute toggle.
* **Character Selection:** Choose from unique low-poly camper avatars before jumping into the world.
* **Cross-Platform Controls:** Seamless support for **PC** (WASD + Mouse) and **Mobile** (virtual thumbstick + touch controls).
* **Dynamic Day & Night Cycle:** Watch the mountain sky shift from bright sunny afternoons to starry nights lit by your campfire.
* **Outdoor Camping Activities:**
  * ⛰️ **Mountain Trekking:** Hike up the scenic trail to the mountain peak viewpoint.
  * 🪓 **Tree Cutting & Firewood:** Chop trees, gather logs, and keep the central campfire burning bright.
  * 🎣 **Fishing & Swimming:** Relax by the lake, go for a swim, or cast a line to catch fish.
* **Campfire Side Games:**
  * 🎬 **Guess the Actor / TV Show:** Compete with friends to guess clues and trivia around the fire.
  * 💬 **Worthwhile Q&A Deck:** Curated, thoughtful, and fun conversation prompts designed to make hangout time memorable.

## 🛠️ Tech Stack

* **3D Engine:** Three.js + Vite
* **Multiplayer & Voice Chat:** PeerJS (WebRTC peer-to-peer data & media streams)
* **Hosting:** Static web deployment (Vercel / GitHub Pages / Netlify)

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com
   cd YOUR_REPO_NAME
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```
4. Open the local URL in your browser (allow microphone permissions to test voice chat).

## 🌐 Deployment

This project is a 100% static web app and can be hosted for free on **Vercel**, **Netlify**, or **GitHub Pages**. *(Note: `HTTPS` is required in production for browser microphone access, which all three hosts provide automatically).*
